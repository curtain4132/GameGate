# GameGate 项目文档

## 开始阅读

1. [产品需求基线 v0.1](requirements/gamegate-product-requirements-v0.1.md)：产品目标、已确认决策、功能、多语言、首版建议、验收标准及待确认事项。推进二开时先阅读此文档。
2. [开源项目调研](research/2026-11-02-open-source-emulator-platforms.md)：RetroArch／Libretro 等项目的能力、复用方向和限制。已确定基于 RetroArch 二开，历史候选比较保留供参考。
3. [Windows 原版构建与启动验证](research/2026-11-02-retroarch-windows-baseline.md)：可复现命令、日志、2048 核心启动证据及尚未覆盖的范围。该文档是验证时的历史记录，不代表仍需重新选择底座。

## 当前明确方向

本地开发仓库已建立，使用方式见 [开发仓库说明](development/repository-workflow.md)。日常从 develop 开发，官方远端为 upstream，产品 origin 暂未配置。

- 基于 RetroArch 二次开发，接受 GPL-3.0 开源分发义务。
- 游戏只能在 App 内运行，不采用外部模拟器启动模式。
- 不考虑 Rust，沿用 C／C++ 与 Libretro 核心生态。
- 分离游戏资源源、游戏资料源和核心仓库。
- 支持统一游戏身份、多语言资料、原文及别名、字段回退和人工纠正。
- 停止追加上游通用能力验证，后续聚焦二开及受影响回归。

六端同步首发、首个资料服务、UI 方案、源协议及受限端随包核心尚未确定。不要把需求基线中的建议项视为已批准实现规格。

## 更新约定

- 新的明确产品决定更新到需求基线，并记录日期；研究记录保留历史事实。
- API 配额、语言覆盖、许可证与分发条件正式接入前重新核查。
- 文档中的目标能力不等于已经实现；实际完成度以代码和验收记录为准。
- 本地构建产物、下载核心和运行数据保存在 `artifacts/`，由 [.gitignore](../.gitignore) 忽略，不作为源码提交。
